ℹ️ Comment ça marche

D’où viennent les séances ?

Horaires, affiches, notes spectateurs et presse viennent d’Allociné, interrogé par notre serveur (méthode de la bibliothèque libre AllocineAPI) puis mis en cache 20 min, avec rafraîchissement en arrière-plan. La ligne « mis à jour il y a X min » indique l’âge des données. Allociné peut avoir un léger décalage avec le cinéma : vérifiez toujours sur la page de réservation.

Ciné IDF n’est pas Pathé

Ciné IDF est un site indépendant, non affilié à Pathé, Gaumont, Allociné ni Letterboxd. On ne vend aucun billet : le bouton « Réserver » vous envoie sur pathe.fr ou le site du cinéma.

Les pastilles

  • VF version française · VOST version originale sous-titrée · ♿ séance accessible (PMR, malentendants, audiodescription selon les salles)
  • IMAX, 4DX, ScreenX, Dolby, 3D : formats premium (souvent avec supplément CinéPass)
  • ★ séance spéciale : avant-première, opéra, concert, live, ciné-débat
  • Contour doré : séance incluse dans votre CinéPass (si vous l’avez renseigné)
  • Affiche grisée : déjà vu sur Letterboxd · badge vert : dans votre watchlist

Letterboxd

Indiquez votre nom d’utilisateur (pas l’e-mail) dans 👤 Compte → Letterboxd. Le profil doit être public. Seuls les films récents sont lus automatiquement ; pour tout l’historique, importez l’export CSV (Letterboxd → Settings → Data → Export).

Places restantes

Allociné ne publie pas le nombre de places : il s’affiche sur la page de réservation du cinéma.

Temps de trajet

Estimation simple à partir de la distance (marche si < 1,2 km, sinon transports en commun ~17 km/h + 10 min). Utilisez le bouton « Itinéraire » pour un calcul précis.

Une séance est fausse ?

Touchez l’horaire puis « ⚠️ Signaler un horaire faux » : le signalement nous parvient en un clic.

Serveur gratuit

Hébergé sur Render (plan gratuit, région Europe non garantie). Après une période d’inactivité, le premier chargement peut prendre jusqu’à ~50 s ; l’app affiche alors les dernières séances enregistrées. Voir la page de statut.
